# Astral End (Fabric 1.21.11)

3 биома Края, 2 моба, 1 босс.

- Биомы: Астральная инфекция, Кристальные поля, Пустотный луг
- Мобы: Астральный паразит, Кристальный каркас
- Босс: Астральный Пожиратель — `/summon astral_end:astral_devourer`

## Сборка через GitHub
1. Залей все файлы в репозиторий (ветка main).
2. Вкладка Actions -> workflow "build" -> дождись зелёной галочки.
3. Внутри запуска скачай артефакт astral-end-mod и достань jar (без -sources).
4. Положи jar в mods вместе с Fabric API 0.141.1+1.21.11.
